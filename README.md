## 🚀 快速开始

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）。
2. 打开工具 →「导入项目」→ 目录选择本项目根目录，AppID 填你自己的（或用「测试号」）。
3. 点击「编译」即可运行 —— **无需开通云开发、无需部署云函数、无任何费用**。
4. 需要真机体验：点「预览」扫码；发布：点「上传」后到 [mp.weixin.qq.com](https://mp.weixin.qq.com) 提交审核。

> 环境要求：基础库 2.2.3+。

## 🧩 技术实现

- **迷宫生成**：`pages/index/index.js` 的 `genMaze(seed, n)` —— mulberry32 种子随机数 + 递归回溯（回溯法）生成完美迷宫（有死路）；`genMazeSafe()` 保证主通路 ≥ 21 格、可放下全部内容点。
- **内容铺放**：`placeContent()` —— 种子洗牌 + 约束重试（间距 ≥ 3、同类最多连续 2 个、教学固定最前），已用脚本对 900 个随机迷宫做过分布校验。
- **代码判分**：`norm()` 归一化空白与中英文引号，`has()` / `hasAll()` 检查关键元素，并对常见等价写法放行，避免"答案写法不同就被判错"。
- **本地存档**：`wx.setStorageSync`，键名 `liam_progress_v2`（进度）/ `liam_stars_v1`（星级）/ `liam_boxdex_v1`（图鉴）。
- **分享海报**：`onMakePoster()` 用 canvas 现绘，无图片资源、不消耗任何额度；只做预览与转发，不写相册。
- **动画剧场**：纯 CSS 关键帧 + 系统 emoji，零额外体积。

## 🔒 隐私与合规

- 代码中**不存在任何隐私接口**：无头像昵称、手机号、位置、相册读写、剪切板、微信运动、麦克风/摄像头、支付。
- 实际使用的接口仅有本地存储、页面跳转、震动反馈、本地音频播放、canvas 绘制 —— 均非隐私接口。
- 程序**零 `wx.request`、零外链**，完全离线可用；无第三方统计 / 广告 SDK。
- 素材均为原创生成或系统 emoji，音效为本地合成，不含第三方闭源库 → **无侵权风险**。
- 详细的审核提交步骤见 **`审核提交说明.md`**。

## ❓ FAQ

| 现象 | 处理 |
|------|------|
| 想重新刷三星但迷宫不变 | 从地图点「已通关」的章节，或通关面板点「重玩本关（换新迷宫）」；首次进入仍是固定迷宫 |
| 迷宫不显示 / 角色不动 | 确认 `index.js` 的 `genMaze` 与 `data/questions.js` 的 `LESSONS` 完整未被改动 |
| 知识卡没声音 | 真机需用户有过交互后才允许播放；模拟器一般正常 |
| 生成分享海报失败 | 确认页面存在 `canvas-id="posterCanvas"`，多为临时失败，重试即可 |
